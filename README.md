# HeritageLens: AR Tourism App 🏛️✨

**HeritageLens** is an Augmented Reality (AR) application designed to preserve cultural heritage by digitizing the **Virtual Monastery Explorer**. It transforms passive sightseeing into an immersive, interactive experience using 360° navigation and AR overlays.

> **Status:** MVP Developed (Hackathon Project)
> **Tech Stack:** Unity 3D, C#, Vuforia Engine, AR Foundation

## 📱 Project Overview
Traditional audio guides are passive and outdated. HeritageLens allows users to scan QR markers at heritage sites to unlock hidden history, view 360° interiors, and listen to location-aware audio narrations.

## 🚀 Key Features
* **Virtual Tours:** Explore monasteries in 360° views from anywhere.
* **AR-Scanning Murals:** Scan artwork to uncover hidden stories using Vuforia Image Targets.
* **Smart Audio Guide:** Location-aware narration about rituals and architecture.
* **Monastery Passport:** A gamified feature to track visits and collect digital stamps.

## 🛠️ Technical Architecture
* **Engine:** Unity 2022.3 LTS
* **Language:** C#
* **AR Framework:** Vuforia Engine & AR Foundation
* **UI/UX:** Figma & Unity Canvas
